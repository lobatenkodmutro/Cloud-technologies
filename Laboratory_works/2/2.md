У ході виконання лабораторної роботи було проведено детальне порівняльне дослідження світових гіперскейлерів та провідних українських постачальників хмарних послуг:
1. Досліджено глобальних лідерів індустрії — AWS, Microsoft Azure та Google Cloud Platform. Встановлено, що кожен провайдер має власну унікальну спеціалізацію: AWS домінує за шириною асортименту (понад 200 сервісів) та зрілістю інфраструктури; Azure є стандартом для корпоративного бізнес-середовища завдяки інтеграції з екосистемою Microsoft та моделями OpenAI; GCP є технологічним лідером у сфері аналітики великих даних (BigQuery) та розгортання контейнеризованих додатків (Kubernetes).
2. Проаналізовано вітчизняний ринок хмарних провайдерів (GigaCloud, DeNovo, UCloud, Tucha, TetCloud). З'ясовано, що українські оператори успішно конкурують завдяки гнучкому тарифоутворенню у гривні, оперативній підтримці державною мовою, наявності атестатів КСЗІ для роботи з державними та персональними даними, а також високій катастрофостійкості завдяки дублюванню майданчиків у країнах ЄС.
3. На практичному прикладі розгортання вебсервера обґрунтовано вибір світової платформи (AWS) з огляду на готові керовані бази даних (RDS) та економічні ARM-процесори Graviton, а також української платформи (GigaCloud) для забезпечення мінімального пінгу в Україні та повної юридичної відповідності стандартам захисту інформації.
